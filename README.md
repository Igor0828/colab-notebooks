# Colab Notebooks

Colecao de notebooks Jupyter/Google Colab produzidos em cursos e estudos de Data Science, Estatistica e Machine Learning (majoritariamente cursos da Alura).

## Temas cobertos

- Estatistica (Partes 1 e 2, estimativas, planejamento de experimentos)
- Introducao a Data Science e Machine Learning
- Classificacao e Regressao Linear
- Limpeza e tratamento de dados
- Visualizacao de dados (matplotlib, folium, estilizacao de tabelas)
- Pandas (selecao, agrupamento, tratamento de dados)
- Projetos aplicados (imobiliaria, extracao de cotacoes, automacao de LinkedIn)
- Data Science aplicada a Saude

## Observacao

Os notebooks sao material de estudo/pratica, sem ordem sequencial obrigatoria - cada arquivo aborda uma aula ou exercicio especifico.
